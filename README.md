## How to Populate This Repo

1. Download each category from [Google Drive — Portafolio](https://drive.google.com/drive/u/0/folders/1YuT0Zl11GJgz0nGuqTAxvNCrWmDK6F9d)
2. Place code in the matching `projects/code/<category>/` folder
3. Place PDFs in `publications/course-reports-2015/`
4. Run `git add . && git commit -m "Add <category> portfolio artifacts"` and push

For full inventory and navigation rules, see [RESEARCH/PORTFOLIO/PORTFOLIO_INDEX.md](https://github.com/pzg8794/RESEARCH/blob/main/PORTFOLIO/PORTFOLIO_INDEX.md).
